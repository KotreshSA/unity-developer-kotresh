Kinect Gesture + Mobile

Temple Run Style Runner - Kinect Gesture and Mobile

A temple run style endless runner built from scratch in Unity and shipped in two versions: a Kinect gesture sensor build for large screens, where players run, jump, slide and dodge with real body movements, and a mobile application build with swipe controls. The track is generated dynamically at runtime, so every run creates a fresh path of tiles, obstacles and coins with no fixed level, and the whole game is fully optimized with object pooling and tile recycling to hold a steady frame rate on both platforms.

Kinect gesture control Mobile application build Dynamic path generation Object pooling and tile recycling Fully optimized performance
